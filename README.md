# Фотостудия «Кадр» — аренда залов и оборудования (вариант 3)

Django-проект: расписание залов, почасовое бронирование, дополнительное световое оборудование и реквизит, гримёрные места, штрафы за порчу, отзывы.

## Быстрый запуск

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env          # затем впишите свой DJANGO_SECRET_KEY (см. комментарий в файле)
python manage.py migrate
python manage.py seed_demo    # демо-данные (повтор: seed_demo --reset)
python manage.py collectstatic --noinput
python manage.py runserver
```

Сайт: http://127.0.0.1:8000/. В сдаваемом варианте `DEBUG=0`; статику и загруженные файлы раздаёт сам Django (учебный режим, см. `config/urls.py`).
Письма по умолчанию печатаются в консоль, где запущен `runserver`.

## Особое требование варианта и где оно реализовано

Всё в `rental/services.py` — на сервере, JavaScript только показывает результат запроса `/api/quote/`.

1. **Стоимость часа зависит от дня недели и времени суток.** Тарифы (`Tariff`) заданы для каждого зала: будни/выходные × утро (08–12) / день (12–18) / вечер (18–23). Каждый час брони тарифицируется отдельно, поэтому бронь, пересекающая границу периодов, считается по двум тарифам (`make_quote`).
2. **Скидка от 3 часов.** `DISCOUNT_FROM_HOURS = 3`, `DISCOUNT_PERCENT = 10` в `config/settings.py`. Скидка действует на аренду зала; оборудование и гримёрные в скидку не входят.
3. **Единицу оборудования нельзя закрепить за двумя залами на пересекающееся время.** Проверка `validate_request` + `busy_equipment_map` (пересечение интервалов `start < end'` и `end > start'` среди активных броней — «ожидает» и «подтверждена»); отменённая бронь освобождает оборудование. Запись брони — `save_booking` под `transaction.atomic` с блокировкой строк (`select_for_update`), поэтому при ошибке в БД не остаётся частичных данных.

## Что проверить на защите (сценарий)

1. Войти как `anna` → «Забронировать» → зал, дата-будни, 11:00, 3 часа: справа видно разбивку «утренний + дневной» и скидку 10%.
2. Отметить оборудование; создать бронь от `ivan` на другой зал и то же время с той же единицей → ошибка «уже закреплено за залом …»; в форме такая единица заблокирована сразу.
3. Открыть `/bookings/<чужой id>/` → 403.
4. Войти как `admin` → подтвердить бронь (письмо в консоли), `/stats/` → показатели и графики.
5. Войти как `tech` → выписать штраф, добавить оборудование с фото.
